Cognitive Load Theory Analysis

Cognitive load theory (CLT) is an instructional design theory that reflects our current knowledge about the human cognitive architecture.

Intrinsic vs Extraneous Load

There are generally considered to be two main types of cognitive load:

  • Intrinsic load: The inherent difficulty of the material itself.
  • Extraneous load: Load generated by the manner in which information is presented to learners.

<h1 align="center">KnowledgeOS</h1>

A personal command center for everything you're learning.

## Workspace

- `apps/web` - Next.js application
- `apps/docs` - Astro documentation site
- `packages/*` - Shared application packages
- `tooling/*` - Shared config for TypeScript, ESLint, and Prettier
- `public/kos-logo.png` - Project logo used in this README

## Stack

- pnpm workspaces
- Turborepo
- TypeScript

## Getting Started

Install dependencies from the repository root:

```sh
pnpm install
```

Common workspace commands depend on the app or package you are working in. Check the package-level `package.json` files for the available scripts.
